# Design System: Rabbit-PF Portfolio

A web developer portfolio website reimagined as an independent artist's personal space. The design blends kitsch, dreamy, playful aesthetics with strong developer credibility.

---

## 1. BRAND & ART DIRECTION

### Overall Concept

This portfolio is a **visual universe** inhabited by three interconnected motifs: a water bottle (personal object / identity), a rabbit (playful mascot), and a galaxy (atmosphere / background). Rather than presenting a sterile portfolio, the website embodies the idea that a developer can have a strong, artistic visual language while maintaining professional credibility.

The visual identity says: **"I am a developer with intention, taste, and a unique perspective."**

### Emotional Keywords

- Dreamy
- Playful
- Slightly nostalgic
- Artistically intentional
- Approachable (not cold)
- Memorable
- Independent-minded
- Tactile
- A little imperfect
- Sophisticated kitsch

### Visual Personality

**What it IS:**
- Editorial and art-directed (like a visual magazine or independent publication)
- Y2K meets contemporary indie artist aesthetics
- Intentional asymmetry and unexpected compositions
- Strong typography and visual hierarchy
- Layered, slightly surreal atmosphere
- Tactile and handmade-feeling elements alongside clean digital surfaces

**What it is NOT:**
- Corporate SaaS minimalism
- Generic "developer portfolio" templates
- Overly polished or sterile
- Trendy gradient spam or glassmorphism
- Excessively abstract or hard to navigate
- Trying too hard to be "cool"
- Indie-for-indie's sake (must remain functional)

### Target Impression for Recruiters

**Conscious design choices → Technical depth**

A recruiter should recognize immediately:
1. This person thinks visually
2. This person has opinion and taste
3. This person can execute (projects are clear and credible)
4. This person is collaborative and thoughtful (not just making something weird)
5. This person brings both technical skill AND artistic perspective to projects

### Developer Credibility + Artistic Identity Balance

- **50% credibility:** Clear project presentation, technical skills, experience, links, standard portfolio elements
- **50% artistic identity:** Visual motifs, playful interactions, editorial layout, unique color palette, intentional typography
- **Result:** A portfolio that doesn't need to choose between being artistic OR professional—it is both

## 3. TYPOGRAPHY

### Font Choices (Web-Safe, Google Fonts)

**Display Font:** `Poppins` (700 weight)
- Used for hero titles, page headers
- Bold, geometric, slightly playful
- Good readability at large sizes
- Modern but nostalgic feel

**Heading Font:** `Outfit` (600 weight)
- Used for section headings, card titles
- Contemporary, clean, slightly geometric
- Sits between playful (Poppins) and functional (body)
- Good for visual hierarchy

**Body Font:** `Inter` (400, 500 weights)
- Used for body text, descriptions
- Highly readable, geometric sans-serif
- Excellent at small sizes
- Professional but approachable

**Caption/Metadata Font:** `Inter` (400 weight, smaller size)
- Used for labels, captions, metadata
- Consistent with body font for coherence
- Smaller size creates distinction

### Size Scale (in pixels / rem)

| Purpose | Size (px) | Size (rem) | Weight | Usage |
|---------|-----------|-----------|--------|-------|
| Hero Title | 72 | 4.5 | 700 (Poppins) | Page hero, main headline |
| Page Title | 48 | 3 | 700 (Poppins) | Section headers, project titles |
| Section Title | 32 | 2 | 600 (Outfit) | Large section headings |
| Heading | 24 | 1.5 | 600 (Outfit) | Card titles, subsections |
| Subheading | 18 | 1.125 | 600 (Outfit) | Small subsections |
| Body Text | 16 | 1 | 400 (Inter) | Main content, descriptions |
| Small Text | 14 | 0.875 | 400 (Inter) | Captions, metadata, labels |
| Tiny Text | 12 | 0.75 | 400 (Inter) | Timestamps, secondary info |

### Letter Spacing & Line Height

| Purpose | Letter Spacing | Line Height | Usage |
|---------|-----------------|------------|-------|
| Display/Hero | 0.5px to 1px | 1.1 | Large titles, tight leading |
| Headings | 0.25px | 1.2 | Section headers, visual impact |
| Body Text | 0.5px | 1.6 | Readable, airy paragraphs |
| Small Text | 0.25px | 1.5 | Captions, dense information |

### Font Features

- **Poppins:** Use all caps sparingly for special sections (e.g., "PROJECTS", "ABOUT")
- **Outfit:** Mix weights (500 for emphasis within 600 headings)
- **Inter:** Use 500 weight for emphasis in body text, slightly darker than 400
- All fonts: Use `-webkit-font-smoothing: antialiased` for refined rendering

## 4. GRID & LAYOUT SYSTEM

### Desktop Layout

- **Max Width:** 1200px
- **Grid Columns:** 12 columns
- **Gutter Width:** 24px (12px on each side)
- **Page Margin:** 40px left/right
- **Section Spacing:** 80px (top/bottom between major sections)
- **Subsection Spacing:** 48px (between related sections)

### Tablet Layout

- **Max Width:** 768px
- **Grid Columns:** 10 columns
- **Gutter Width:** 20px
- **Page Margin:** 24px left/right
- **Section Spacing:** 60px
- **Subsection Spacing:** 40px

### Mobile Layout

- **Max Width:** 100%
- **Grid Columns:** 6 columns (or 2 columns for simple layouts)
- **Gutter Width:** 16px
- **Page Margin:** 16px left/right
- **Section Spacing:** 48px
- **Subsection Spacing:** 32px

### Spacing Scale (Design Tokens)

| Name | Value (px) | Value (rem) | Usage |
|------|-----------|-----------|-------|
| `--space-xs` | 4 | 0.25 | Tight spacing, icon margins |
| `--space-sm` | 8 | 0.5 | Small gaps between elements |
| `--space-md` | 16 | 1 | Default spacing, list items |
| `--space-lg` | 24 | 1.5 | Section padding, card spacing |
| `--space-xl` | 40 | 2.5 | Large sections, headers |
| `--space-2xl` | 60 | 3.75 | Between major sections |
| `--space-3xl` | 80 | 5 | Hero section spacing |

### Card & Container Spacing

- **Card Padding:** 32px (desktop), 24px (tablet), 16px (mobile)
- **Card Border Radius:** 12px
- **Card Spacing Between:** 24px
- **Project Card Width:** Varies (see projects section)

### Intentional Asymmetry Principles

1. **Overlapping Elements:** Allow cards, images, and text to overlap vertically by 12-24px
2. **Floating Objects:** Use `transform: translateY()` for subtle floating, not perfectly aligned
3. **Unexpected Alignment:** Text and images can break the grid by ±1 column
4. **Whitespace Contrast:** Use large negative space next to dense areas
5. **Varied Heights:** Cards and sections should have different heights for visual rhythm
6. **Angled Elements:** Subtle 2-3 degree rotations for playfulness (sparingly)

## 5. VISUAL LANGUAGE

### Shapes & Borders

- **Button Border Radius:** 8px (slightly rounded, not fully pill-shaped)
- **Card Border Radius:** 12px
- **Large Section Border Radius:** 16px
- **Input/Form Border Radius:** 8px
- **Decorative Element Radius:** 20px+ (more organic)

### Border Styles

- **Primary Borders:** 2px solid, `--color-twilight-gray` (`#E8E6F0`)
- **Subtle Borders:** 1px solid, `--color-silver-mist` (`#D9D7E3`)
- **Accent Borders:** 2px solid, `--color-cosmic-lavender` (`#B5A7D6`)
- **No borders on cards by default—use subtle shadow instead**

### Shadows

- **Subtle Shadow (default cards):** `0 2px 8px rgba(26, 22, 41, 0.08)`
- **Medium Shadow (hover state):** `0 4px 16px rgba(26, 22, 41, 0.12)`
- **Deep Shadow (prominent cards):** `0 8px 24px rgba(26, 22, 41, 0.15)`
- **Inset Shadow (depth):** `inset 0 1px 3px rgba(26, 22, 41, 0.05)`

### Textures & Grain

- **Subtle Noise Overlay:** Optional 2-3% opacity noise texture on background and large sections
- **Grain Purpose:** Adds tactile, imperfect feel without being distracting
- **Implementation:** SVG pattern or subtle PNG overlay
- **Apply to:** Galaxy backgrounds, large decorative areas, not primary content areas

### Gradients

- **Galaxy Gradient:** `linear-gradient(135deg, #8B5A8E 0%, #2D1B3D 50%, #4A9BA8 100%)`
- **Subtle Fade:** `linear-gradient(to right, rgba(0,0,0,0.1) 0%, transparent 50%, rgba(0,0,0,0.1) 100%)`
- **Warm-to-Cool:** `linear-gradient(135deg, #F5D5B8 0%, #B5A7D6 100%)`
- **Neon Accents:** Avoid—use solid colors instead

### Blur & Transparency

- **Frosted Glass (rare):** `backdrop-filter: blur(8px)` with 0.8 opacity (use sparingly)
- **Fade Overlays:** `background: linear-gradient(to bottom, transparent 0%, rgba(0,0,0,0.1) 100%)`
- **No heavy blur—preserve readability**

### Stickers & Decorative Objects

- **Sticker Style:** Flat, slightly imperfect illustrations
- **Sticker Borders:** Thin 1px border or subtle drop shadow
- **Sticker Colors:** Use secondary color palette
- **Placement:** Float at 2-5 degree angle, positioned outside grid
- **Opacity:** Some stickers at 80% opacity for layered effect
- **Purpose:** Break visual monotony, add personality, don't interfere with content

### Handwritten & Doodles

- **Handwritten Font:** Optional `Caveat` (Google Fonts) for rare annotations
- **Doodles:** Minimal, thin-line doodles in galaxy/rabbit themes
- **Usage:** Sparingly—maybe project annotations, section labels
- **Style:** Hand-sketched but not childish, organic but intentional

### Decorative Objects

- **Water Bottles** (small floating bottles): Positioned outside main content grid
- **Rabbit:** Main interactive character (see motifs section)
- **Stars:** Scattered in background, fade in/out with animation
- **Floating Particles:** Subtle, slow-moving background elements
- **No excessive decoration—every element should serve a purpose**

### Image Treatment

- **Project Screenshots:** 
  - Border: 2px solid `#E8E6F0` or subtle shadow
  - Border Radius: 8px
  - May have slight rotation (2-3 degrees)
  - Possible subtle grain overlay

- **Headshots/Profile Images:**
  - Border: 3px solid `#B5A7D6`
  - Border Radius: 12px to 20px (organic, not circular)
  - Optional soft vignette around edges

- **Decorative Images:**
  - Can be more artistic, less structured
  - May use opacity layering
  - Can overlap text (with readability maintained)

## 6. THREE CORE MOTIFS

These three elements form the visual identity system and should recur throughout the website.

### 🍶 WATER BOTTLE (Identity, Daily Object)

**Visual Concept:** A stylized water bottle as a personal symbol. It represents consistency, hydration, preparation, and the everyday rituals of a developer.

**Shape & Design:**
- Simple silhouette: curved body, flat top cap, slight taper at base
- Not ultra-realistic, but recognizable
- Approximate proportions: height 2x width
- Cap: small rectangle or circle, metallic gold accent
- Can show water inside bottle (wave animation optional)

**Colors:**
- Primary bottle: `#C5E8E8` (light cyan glass)
- Water inside: `#5DADE2` (saturated blue)
- Shadow on bottle: `#7BA3A8` (darker cyan)
- Cap: `#F4D46F` (gold/metallic)
- Highlights: white/very light cyan

**Where It Appears:**
1. Homepage hero (subtle, background)
2. About section (larger, character-like)
3. Contact section (floating)
4. Page transitions (small animation)
5. Footer (tiny, repeated pattern)

**Animation Possibilities:**
- Slow floating (Y-axis): ±10px every 3 seconds
- Gentle rotation: ±2 degrees
- On hover: slight scale up (1.05x)
- On scroll: parallax movement

**How It Represents the Developer:**
- "I stay hydrated and present" → reliability, daily commitment
- "I prepare before I code" → intentionality
- "Simple but essential" → pragmatic approach

**Component Name:** `<WaterBottle />` (variants: small, medium, large)

---

### 🐰 RABBIT (Playful Mascot)

**Visual Concept:** A charming rabbit character that appears throughout the site. It embodies playfulness, curiosity, and wonder. The rabbit is approachable and slightly naive, offsetting the technical nature of web development.

**Character Style:**
- Simplified, illustrative style (not realistic)
- Proportions: Medium-sized head, medium ears, small body
- Expression: Curious, friendly, sometimes introspective
- Poses: Standing, sitting, floating, thinking
- Art style: Flat color with subtle shading, not photorealistic

**Design Details:**
- Eyes: Simple black circles or dots with highlight
- Nose: Triangle or small circle, `#D9A4A4` (rabbit pink)
- Ears: Prominent, can be expressive (perked up, droopy)
- Fur Base: `#F5E6D3` (cream)
- Inner Ears & Nose: `#D9A4A4` (rose)
- Shadows: `#8B6F47` (brown)

**Expressions & Poses:**
- Thinking/curious (hand on chin)
- Happy (jumping or floating)
- Excited (ears up, eyes wide)
- Contemplative (sitting, looking away)
- Confused/questioning (head tilt)

**Where It Appears:**
1. Homepage (introduction section)
2. Projects page (comment on projects, celebratory)
3. About section (character-driven storytelling)
4. Hover states (subtle appearance)
5. Error states or loading states
6. Contact section (greeting)

**Animation Possibilities:**
- Micro-movements: subtle ear twitch, eye blink (every 2-3 seconds)
- Floating: ±15px Y-axis movement
- On scroll: parallax, appearing/disappearing
- On hover: look toward cursor (eye movement)
- Celebration animation: jump, spin
- Thinking animation: hand to chin, pause

**How It Interacts with UI:**
- Can appear next to project cards with commentary
- Can point to important information
- Can react to user actions (surprised on hover, happy on project click)
- Doesn't block content, positioned in margins or floating

**Component Name:** `<Rabbit />` (variants: thinking, happy, surprised, floating)

---

### 🌌 GALAXY (Atmosphere, Depth, Background)

**Visual Concept:** A dreamlike galaxy/nebula atmosphere that appears throughout the site. It represents the vast, creative, exploratory nature of web development. The galaxy is a mood-setter, not a distraction.

**Background Treatment:**
- **Primary Galaxy Gradient:** `linear-gradient(135deg, #8B5A8E 0%, #2D1B3D 50%, #4A9BA8 100%)`
- **Soft, blurred nebula clouds** with organic shapes
- **Multiple layers** for depth (background, middle, foreground stars)
- **Never entirely opaque**—background elements show through

**Stars:**
- **Scattered stars** at varying opacity (20% to 80%)
- **Sizes:** Mix of 2px, 4px, and 6px circles
- **Colors:** Mostly `#F4D46F` (gold) with some `#FFFFFF` (white) and rare `#A8D4D4` (cyan)
- **Twinkling animation:** Subtle opacity change every 2-4 seconds
- **Random placement:** Not perfectly aligned, slightly organic

**Nebula Clouds:**
- **Soft, blurred circular/organic shapes**
- **Colors:** Mix of `#8B5A8E` (purple) and `#4A9BA8` (cyan)
- **Opacity:** 30-50% so background content remains readable
- **Positioned:** Background layer, doesn't interfere with text

**Parallax & Motion:**
- **Subtle parallax** on scroll (moves slower than page content)
- **Very slow drift** animation (entire background shifts very slightly, every 30+ seconds)
- **No distraction**—just atmospheric presence

**Where It Appears:**
1. **Hero Section:** Full background, strong presence
2. **Page Transitions:** Flowing galaxy effect between pages
3. **Project Detail Pages:** Subtle background layer
4. **Section Dividers:** As a visual break between sections
5. **Floating Elements:** Galaxy wisps around rabbit, bottles
6. **Not everywhere:** Content sections have clean `#F7F5FB` background

**Component Name:** `<GalaxyBackground />` (variants: hero, subtle, sections)

**Implementation Details:**
- SVG or canvas for stars and nebula
- CSS gradient for base color
- CSS animation for twinkling
- Intersection Observer for parallax
- Respects `prefers-reduced-motion` (stops animation, keeps static beauty)

## 7. PAGE STRUCTURE & INFORMATION ARCHITECTURE

This is a job-seeking web developer portfolio, so projects and technical ability are prioritized.

### Navigation

- **Sticky Header:** Small, persistent navigation at top
- **Navigation Items:** HOME, PROJECTS, ABOUT, CONTACT
- **Logo/Brand:** Initials or small water bottle icon (clickable home link)
- **No mega-menu or complex navigation**—simple and clear

### HOME PAGE

**Purpose:** Immediate impression, showcase personality, direct to projects

**Sections (in order):**

1. **Hero Section** (full viewport, 80-100vh)
   - Large title (developer name or intro statement)
   - Subheading (one-liner about what you do)
   - Subtle galaxy background
   - Small rabbit character (floating, curious)
   - Floating water bottle
   - CTA button ("View Projects")
   - Animation: Gentle fade-in on load

2. **Identity Statement** (60px section)
   - Bold headline (20-24px)
   - 2-3 sentence intro about the portfolio approach
   - Explains: developer + artist

3. **Featured Project** (400-500px section)

   - Title, tech stack, short description
   - Asymmetric layout (image left, text right OR staggered)

   - Link to full project details

4. **Project Grid/Gallery** (600px section)
   - 3-4 featured projects in gallery layout
   - Cards with images, titles, tech tags

5. **Developer Capabilities** (400px section)
   - What skills/tech the developer has
   - 3-4 key areas: Frontend, Backend, Design, [Other]

6. **About / Personal** (600px section)
   - Photo + short bio
   - "Why I design like this" brief explanation
   - Personal interests, links
   - Rabbit character present (commenting or sitting with)

7. **Contact Section** (300px section)

8. **Footer** (100px section)

## 10. MOTION DESIGN

All animations should respect `prefers-reduced-motion: reduce` (disable animations, keep static state)

### Persistent Animations

**Rabbit Micro-movements** (repeat every 2-3s)
- Eyes blink (100ms close/open)
- Ears twitch (slight rotate, 150ms)
- Head tiny tilt (100ms)
- Tail wiggle (200ms, if tail exists)

**Water Bottle Floating**
- Y-axis movement: ±10px, duration 3s, ease-in-out
- Gentle rotation: ±2°, duration 5s
- Repeats infinitely

**Stars Twinkling**
- Random stars fade in/out
- Duration: 2-4s per star
- Offset starts for variation
- Opacity: 20% → 80% → 20%

**Galaxy Drift**
- Entire background shifts slowly
- Duration: 30-40s
- Movement: ±5% horizontal/vertical
- Very subtle, atmospheric

### Interactive Animations

**Button Hover**
- Background color: Deep Space → Cosmic Lavender (200ms)
- Scale: 1 → 1.02x (150ms)
- Shadow: Subtle → Medium (150ms)

**Card Hover (Projects)**
- Image scale: 1 → 1.03x (250ms)
- Shadow depth increase (250ms)
- Title color: Deep Space → Cosmic Lavender (200ms)

**Link Hover**
- Color change (150ms)
- Underline appears (if not present)
- No scale or drastic changes

**Rabbit Look Toward Cursor** (on hover, if implemented)
- Eye position follows cursor
- Duration: 100ms per update
- Smooth easing

**Rabbit Celebration** (on project click)
- Jump animation: Y-axis ±30px, 500ms, ease-out
- Spin: 360° rotation, 600ms
- Stay in place briefly, then return

### Page Transitions

**Between Pages**
- Fade out current page: 200ms
- Galaxy swipes across screen: 300ms
- Fade in new page: 300ms

**Scroll Animations**
- Elements fade/slide in as scrolled into view
- Duration: 600ms
- Fade: 0% → 100% opacity
- Slide: ±20px to center position

**Parallax (Subtle)**
- Background galaxy moves slower than foreground
- Scroll factor: 0.5x (background moves half as fast)
- Subtle only—not disorienting

### Animation Parameters

| Animation | Duration | Easing | Repeat |
|-----------|----------|--------|--------|
| Rabbit blink | 100ms | ease-out | 2s interval |
| Rabbit ear twitch | 150ms | ease-in-out | 2.5s interval |
| Water bottle float | 3s | ease-in-out | infinite |
| Stars twinkle | 2-4s | ease-in-out | infinite |
| Galaxy drift | 30s | linear | infinite |
| Button hover | 150-200ms | ease-out | on hover |
| Card hover | 250ms | ease-out | on hover |
| Page fade | 200-300ms | ease-in-out | on navigation |
| Scroll reveal | 600ms | ease-out | on scroll |

### Accessibility

- All animations respect `prefers-reduced-motion: reduce`
- When reduced-motion is active: Remove all animations, keep static state
- Animations do NOT flash or flicker (prevent seizure triggers)
- Focus indicators remain visible during animations
- Never animate form inputs themselves (only backgrounds/borders)

### Desktop (1200px+)

- Floating elements fully visible
- 2-3 projects per row in gallery
- Rabbit character visible and interactive
- Large hero images

- Floating elements repositioned (not off-screen)
- Projects gallery: 2 per row
- Slightly smaller type sizes
- Navigation items may stack
- Rabbit visible but smaller
- Simplified animations (reduce movement range)

### Mobile (< 768px)

- Simplified grid: 2-6 columns
- Single-column primary content
- Floating elements integrated into main column (not truly floating)
- Projects gallery: 1 per row with carousel or stacked
- Smaller hero image
- Text sizes scaled appropriately
- Rabbit simplified (appear/disappear based on space)
- Animations simplified (disable some micro-movements)
- Navigation: Hamburger menu or simplified

### Mobile-Specific Adjustments

- Hero title: 48px (down from 72px)

## 14. DESIGN PRINCIPLES & GUARDRAILS

### Do's

✅ Use asymmetric, editorial layouts  
✅ Prioritize information hierarchy over decoration  
✅ Make project details crystal clear  
✅ Use the three motifs meaningfully (not as decoration)  
✅ Keep animations subtle and purposeful  
✅ Maintain strong visual identity  
✅ Test on real devices (mobile, tablet, desktop)  
✅ Respect accessibility (WCAG AA minimum)  
✅ Use negative space intentionally  
✅ Mix playful elements with professional content  

### Don'ts

❌ Don't make it look like a generic SaaS product  
❌ Don't use glassmorphism excessively  
❌ Don't animate everything  
❌ Don't sacrifice readability for aesthetics  
❌ Don't use overly bright neon colors  
❌ Don't hide important information under visual effects  
❌ Don't use the motifs as pure decoration (make them meaningful)  
❌ Don't make it feel dated or gimmicky  
❌ Don't use low-contrast text  
❌ Don't forget mobile users  

### Accessibility Requirements

- Minimum contrast ratio: 4.5:1 (body text), 3:1 (large text)
- Focus indicators always visible
- Keyboard navigation works everywhere
- Images have alt text
- Forms have proper labels
- Color is not the only information conveyor
- Animations respect `prefers-reduced-motion`
- Mobile touch targets: minimum 44x44px
